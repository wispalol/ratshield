What it does

Real-time protection

Folder monitors react to creates, changes and deletions. Files that look dangerous are quarantined before you can double-click them, and deletions inside watched folders are logged.

Scans that finish

Quick, full and custom scans run on a background worker with live progress, a cancellable queue, per-file findings and a written summary of what was scanned, found and quarantined.

Transparent risk scoring

Every verdict is a list of reasons with points: signed or not, where it lives, what it contains, what it tried to do. Duplicates are merged, capped scores are explained.

Rules you can write

A YARA-subset parser loads plain text rule files from disk: strings, hex patterns, and/or/not, any of ($x*), filesize, meta severity and expected SHA-256.

Quarantine with receipts

Quarantined files are moved, hashed and recorded with the rule or reason that caught them. Restore with one click (overwrite is asked for explicitly), or delete permanently.

System awareness

Live network connections, persistence entries (Run keys, startup folder, services, scheduled tasks), firewall state, process list and signature checks - collected through plain Windows commands, no driver required.

How a file gets a verdict

  1. ClassifyExtension, magic bytes and PE header decide the type and whether deep inspection is worth it.
  2. CollectHashes, embedded strings, entropy, imports, sections, timestamps, code signature, location and age.
  3. MatchLoaded rules run against content (bounded to the first 8 MB) and against the expected SHA-256.
  4. ScoreEach signal contributes points; duplicates count once, weak combinations earn a capped synergy bonus.
  5. ActAllow, warn, confirm or quarantine - then the reason list is published to the activity log on screen and on disk.

Bounded by design

Archives are limited to 2 000 entries, a 200:1 compression ratio and 3 levels of nesting. Files above the configured size limit are skipped by scans instead of hanging them. Rule evaluation stops at 8 MB of content.

Graceful on any machine

Windows diagnostics degrade to a clear message when a command is refused: no admin rights means firewall changes report "elevation required" instead of failing silently.

Scoring and thresholds

Scores are clamped to 0-100. The default action thresholds are configurable in Settings.

BandScoreDefault action
SAFE0 - 19Allow
LOW20 - 39Allow
SUSPICIOUS40 - 59Warn
HIGH60 - 79Quarantine
MALWARE80 - 100Quarantine and confirm
  • A valid code signature caps an otherwise unconfirmed score at 55.
  • A rule hit, a reputation hit or an archive bomb marks the verdict CONFIRMED and quarantines regardless of score.
  • Confidence also counts categories: file structure, location and timing, observed behaviour, signatures.

Rules are plain text

Drop a .rules file into the rules folder and press Reload on the Rules page. Every rule needs a meta severity.

rule Suspicious_PowerShell_Encoded_Command : powershell
{
    meta:
        description = "PowerShell invoked with an encoded or hidden command line"
        severity = "high"
        id = "core.ps.encoded"
    strings:
        $enc1 = "-EncodedCommand" nocase
        $enc2 = "-enc " nocase
        $host1 = "powershell" nocase
        $hide1 = "-w hidden" nocase
    condition:
        (any of ($enc*)) and (any of ($host*)) and (any of ($hide*))
}

Supported modifiers: nocase, wide, ascii, fullword, xor, base64, base64wide, plus hex patterns with ?? wildcards. Parse errors are listed on the Rules page instead of being silently dropped.

Build it yourself

Requirements: JDK 21 (Temurin or newer) and Maven 3.9+. On Windows, the packaged app is produced with the JDK's own jpackage.

# run the test suite
mvn -B test

# build the shaded jar and run it
mvn -B clean package
java -jar target/RATShield.jar

# build the Windows app image: target/dist/RATShield/RATShield.exe
mvn -B package -Pdist

Runs anywhere Java does

The jar starts on any platform with a display. Windows-specific views show their real diagnostic output instead of empty tables when a command is unavailable.

No services, no drivers

Everything is user-space: folder watchers, polling monitors and command-line queries such as netstat, reg, net session and netsh.

Your data stays local

Config, log, quarantine, reputation cache and learned hashes live in one folder under %LOCALAPPDATA%\RATShield. No account, no upload.
